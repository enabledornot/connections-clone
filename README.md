# connections-clone

This is intended to be a clone of the popular NYT game connections.

It is able to pull the current, past and future connection boards from the NYT official website. In order to get around CORS it uses a CORS proxy (`https://proxy.cors.dev/`). If at some point this public CORS proxy gets overloaded the websites ability to load the official NYT connection boards will fail.

View a live demo by clicking the link below
